# Reroll Trades 3.1.0

Reroll villager offers instantly with a button or the configurable R key. Rerolls are completely free: no emeralds, experience, or items are consumed.

Version 3.1.0 adds a safe one-step Undo, server-side cooldowns, optional reroll limits, client settings, and consistent Fabric/NeoForge behavior. Once any player completes a trade with a villager, that villager can no longer be rerolled by anyone.

The server controls every operation and the controls remain hidden for unsupported merchants. Fabric users can optionally configure client settings through Mod Menu; NeoForge users can open the settings screen from the mod list.

Server operators can edit `reroll-trades-server.json` and use `/rerolltrades reload` or `/rerolltrades status` with permission level 2.
